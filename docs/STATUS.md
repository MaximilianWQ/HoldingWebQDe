## Как проверять и выкладывать

1. Снимок коммита: `git archive <sha> | tar -x -C <dir>`, затем `npm ci`
   (или симлинк на готовые `node_modules`), `npx tsc --noEmit -p .`,
   `npx vitest run`, `npx next build`.
2. **Файлы в коммит добавлять по одному** (`git add -A -- путь`) и проверять
   число застейдженных файлов: в zsh список из переменной не разбивается и
   коммит выходит пустым (так случился `4d17f74`).
3. После выкладки проверять на проде само изменение, а не только коды ответа.
