# Что задать в Railway

Сервис сайта → Variables. Всё несекретное уже записано в коде — это
задавать не нужно:

- адрес сайта — qodev.dev;
- домен быстрого входа;
- основной бот — `atlassecure_bot`;
- сквад обхода;
- лимит устройств обхода.

## 1. Секреты — проверить, что заданы

Секреты не пишутся в код и не присылаются в чат. Большинство уже стоит,
раз сайт работает; достаточно проверить, что строки есть.

| Переменная | Откуда значение |
|---|---|
| `DATABASE_URL` | Postgres в Railway (обычно подставляется сам) |
| `RESEND_API_KEY` | resend.com → API Keys |
| `REMNAWAVE_API_URL`, `REMNAWAVE_API_TOKEN` | панель Remnawave |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` | личный кабинет ЮKassa |
| `BOT_API_KEY` | **то же значение, что в настройках бота**; без совпадения бот не сможет привязывать почту и продлевать |
| `REMNAWAVE_WEBHOOK_SECRET` | **то же значение, что в настройках вебхука панели** |
| `CRON_SECRET` | любая длинная случайная строка; её же указать в задаче cron |
| `VAPID_PRIVATE_KEY`, `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | нужны только для push-уведомлений |

## 2. По желанию

| Переменная | Что делает |
|---|---|
| `RESEND_DAILY_LIMIT` | сколько писем рассылки уходит за сутки; по умолчанию 80 (из 100 бесплатных Resend, 20 остаются кодам входа). Задавать, только если перейдёте на платный тариф Resend |

## Никогда не задавать на проде

- `YOOKASSA_API_URL_OVERRIDE`
- `CAMPAIGN_DEV_OUTBOX`

Это подмены только для локальных проверок: с ними оплаты и письма уйдут
не туда.
